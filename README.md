- About
- Smart Notes + Tutor featured project
- COVID-19 Lung Infection Segmentation
- Student Attendance Tracker
- Internship experience
- Education
- Skills and certifications
- Paper presentation
- Contact section

## Run locally

This version is a simple static website. Open `index.html` in a browser, or run a local server from this folder:

```bash
python -m http.server 5500
```

Then open `http://localhost:5500`.
